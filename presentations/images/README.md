# Presentation Images Directory

Place screenshots of your mobile app in this folder.
Suggested naming convention:
- `lab-1.png` - Lab 1 App Screenshot / Expo Go
- `lab-2.png` - Lab 2 Event Cards & List UI
- `lab-3.png` - Lab 3 Responsive Layout & Styling
- `lab-4.png` - Lab 4 Tabs Navigation & Detail Screen
- `lab-5.png` - Lab 5 Create Event Modal / Form
- `lab-6.png` - Lab 6 API Data Loading & Events List
- `lab-7.png` - Lab 7 Saved Favorites / Offline Storage
- `lab-8.png` - Lab 8 Login & Auth Flow
- `lab-9.png` - Lab 9 Camera / Image Picker
- `lab-10.png` - Lab 10 Maps & Location Picker
- `lab-11.png` - Lab 11 Local Notifications Reminder

In `slides.md`, uncomment the `<img>` tag in each slide and specify your image file path:
```html
<img src="./images/lab-1.png" alt="Lab 1" class="w-full h-full object-cover rounded-2xl" />
```
